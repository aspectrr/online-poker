# web

SolidJS + TS + Tailwind, built and served entirely with [Bun](https://bun.sh) — runtime, package manager, and Vite runner. No Node involved.

```sh
bun install
bun run dev      # dev server (Vite on the Bun runtime)
bun run build    # typecheck (tsc on Bun) + production build → dist/
bun run preview  # serve the production build
```
